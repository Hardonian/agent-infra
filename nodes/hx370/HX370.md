## Role in the stack

HX370 is the **interactive development, verification, private-review, and selectively-enrolled
execution node**. It optimizes for Scott's responsive daily use: fast repository work, local
browser/UI checks, lightweight research, and secure access to shared services.

EPYC (reachable at `100.127.74.34` via Tailscale) is the candidate for **sustained inference and
always-on shared services** — but ownership is *verified per-dispatch, not assumed*. This node
never migrates a service to EPYC, and never claims an EPYC capability it has not observed.

| Work | HX370 responsibility | EPYC relationship |
|---|---|---|
| Repository implementation | Local edits, isolated worktrees, bounded tests/builds, UI verification | Offload only explicitly-supported expensive work through authenticated jobs |
| Human interaction | Terminal, private dashboard/review, Android/Termux-compatible access | Show remote availability + actual job status |
| Model use | Existing local lightweight models **only when measured suitable** | Route heavier inference through the verified existing gateway |
| Shared jobs/memory | Scoped client/worker; bounded local staging | One authoritative owner for queues/schedules/policy/durable records |
| GPU/NPU tasks | Only capability-proven backend workloads | AMD acceleration ≠ NVIDIA CUDA compatibility |
| Offline use | Local authorized edits/checks, drafts, marked-pending submissions | Reconnect + reconcile; never a second scheduler or duplicate effect |

### Acceleration reality (do not over-claim)
- **GPU compute: UNTESTED / unsupported locally.** `/dev/dxg` and the Windows driver prove the
  device exists, but there is **no ROCm, HIP, DirectML, or torch runtime installed in WSL**. Per
  policy a device listing is *not* compute evidence, so all local work defaults to **CPU** or routes
  to the **verified remote gateway**. Installing ROCm/DirectML/Vulkan/NPU stacks is out of scope for
  this release (needs concrete need + authorization). The iGPU **shares system RAM** — never add its
  advertised memory to the 19.5 GiB as if independent.
- **NPU compute: UNTESTED / unsupported.** No device node or kernel module is present. Marketing
  TOPS is not application-acceleration evidence.
